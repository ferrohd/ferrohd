This is the first post on my new blog, rebuilt from scratch with [Zola](https://www.getzola.org/) — a fast static site generator written in Rust.

<!-- more -->

## Why Zola?

The previous version of this site was a Next.js app. It worked fine, but it felt like overkill for what is essentially a personal homepage and blog. I wanted something simpler:

- **No JavaScript** — the site is pure HTML and CSS
- **Fast builds** — Zola compiles the entire site in milliseconds
- **Markdown content** — writing posts is just creating `.md` files
- **Single binary** — no `node_modules`, no dependency tree to maintain
